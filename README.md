# Hotel Website (early version)

First version of the hotel booking website: a hotel home page, a Goa property page and a login screen.

## Features

- Hotel home page with rooms, services and gallery
- Goa property page
- Login / signup form

## Tech stack

HTML5, CSS3, JavaScript

## Structure

```
index.html      Redirects to hotel/hotel.html
hotel/          Home page
goa/            Property page
login/          Sign in / sign up
```

## Run locally

No build step. Clone the repo and open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
